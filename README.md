OperationsManager: Terminal File Manager & Operations SuiteOperationsManager is a lightweight, self-contained terminal file manager and operations suite powered by an embedded PowerShell and C# Console API engine wrapped in a standard Windows batch script. It provides a responsive, interactive text-user interface (TUI) directly inside the Windows console for local navigation, file manipulation, and administrative operations.   🚀 Key FeaturesInteractive Terminal User Interface (TUI): Built on low-level Win32 ConsoleApi hooks using inline C# structs (CHAR_INFO, INPUT_RECORD, CONSOLE_SCREEN_BUFFER_INFO), supporting keyboard and precise mouse interactions.   File & Directory Management: Browse local drives, navigate directory trees, view file sizes and timestamps, and open files or directories seamlessly.   Advanced Operations Suite:Context-aware Actions Menu (M key or mouse click) for files and folders.   File and folder creation tools (N key).   Copy, move, rename, and recursive delete capabilities.   Secure password-protected confirmation workflows for sensitive tasks like deletion and moving.   Detailed Property Inspector: Deep-dive inspection view for file attributes, exact byte sizes, creation/modification timestamps, and security descriptors (file owners).   Embedded Command Shell Launcher: Quick terminal escape (C key) to spawn a customized cmd.exe process directly within the working directory context.   🛠️ Technology StackScripting & Automation: Windows Batch (.bat) / Command Processor (cmd.exe)   TUI Engine: PowerShell (v5.1+ / v7+)   Win32 Interop Layer: Inline C# compilation via Add-Type managing kernel32.dll standard handles, console modes, screen buffers, and raw input/output records   📁 Project StructurePlaintextOperationsManager/
